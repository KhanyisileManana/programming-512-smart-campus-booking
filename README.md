
# Smart Campus Resource Booking System

## Project Overview

A Python desktop application developed using Tkinter
and SQLite to manage campus resource bookings.

## Main Features

- Lecturer registration and login.
- Resource booking.
- Booking cancellation.
- Prevention of overlapping bookings.
- Campus-specific booking policies.
- Administrator resource management.
- Campus usage reports.
- Cross-campus reports.

## Technologies Used

- Python
- Tkinter
- SQLite
- Object-Oriented Programming
- Strategy Design Pattern

## How to Run

First initialize the database:

python seed_resources.py

Then start the application:

python main.py
